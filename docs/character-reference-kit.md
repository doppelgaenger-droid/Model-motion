# Character Reference Kit · Canonical v1.0

Every new adult character starts with **one supplied reference image**. Generate three coordinated images, preserving identity, hairstyle, distinguishing traits, and proportions without inventing canonical details not supported by the reference.

## Fixed deliverables and filenames
Use lowercase kebab-case character slug, and preserve this sequence:

1. `<character-slug>_01_identity-reference.png` — single canonical portrait, neutral readable lighting, front or three-quarter view, clear facial identity.
2. `<character-slug>_02_character-board.png` — coherent character board showing facial expressions, hair and palette, wardrobe details; all depictions must be consistent with the source.
3. `<character-slug>_03_full-body-reference.png` — full-body front, side, and back turnaround with consistent proportions and outfit.

## Visual language
- Consistent dark editorial studio layout across all three deliverables.
- Same typography, margins, grid, section numbering, title placement, and understated accent system.
- Clear subject/background separation; neutral framing suitable for production reference.
- Avoid decorative changes in illustration/render style between sheets.
- Each sheet must have a readable title, character slug, and numbered reference type.
- Export three **separate** images, not a single triptych.

## Canonical workflow
- The supplied source reference is the identity authority.
- The generated sheets are proposed canonical assets until reviewed and approved by the user.
- Upload each sheet into its matching fixed slot. Replacing an image must not reorder the slots.
- Character-specific appearance and palette may vary; the layout system stays consistent.
- Do not claim that source likeness, full-body details, or reverse views are verified when inferred.

This file defines the production standard, not an automatic image-generation integration.
